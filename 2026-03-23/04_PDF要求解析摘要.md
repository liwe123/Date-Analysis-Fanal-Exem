## 来自《实验04 – 压缩战争》

1. 数据构建：
- 用 Python + pandas 构建约 100 万行数据，形成较大内存占用。

2. 存储对比：
- 同一数据保存为 CSV、JSON、Parquet。
- 比较三者文件大小。

3. 查询对比：
- 对“平均价格”场景做读取计时。
- 体现 CSV 行式读取与 Parquet 列式读取差异。

4. 模式防御：
- 尝试引入坏数据（如 `price='Expensive'`）并观察类型约束。

5. 评分关键点：
- 必须给出指标：`1 - (Parquet大小 / JSON大小)`；
- 必须用两句 Markdown 解释字典编码；
- 必须使用 `time.time()` 或 `%%time` 给出速度证据；
- 提交 `.ipynb`。
