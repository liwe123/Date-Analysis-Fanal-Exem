文件打开模式

Python使用open()函数打开文件，第二个参数指定打开模式：

  • 'r'：只读模式（默认）
  • 'w'：写入模式，会覆盖文件内容
  • 'a'：追加模式，在文件末尾添加内容
  • 'x'：创建模式，如果文件已存在则报错
  • 'b'：二进制模式
  • 't'：文本模式（默认）

读取文件

# 读取整个文件
with open('example.txt', 'r', encoding='utf-8') as f:
    content = f.read()
    print(content)

# 逐行读取
with open('example.txt', 'r', encoding='utf-8') as f:
    for line in f:
        print(line.strip())

# 读取所有行到列表
with open('example.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()
    print(lines)

写入文件

# 写入字符串
with open('output.txt', 'w', encoding='utf-8') as f:
    f.write("Hello, World!\n")
    f.write("这是第二行\n")

# 写入多行
lines = ["第一行\n", "第二行\n", "第三行\n"]
with open('output.txt', 'w', encoding='utf-8') as f:
    f.writelines(lines)

# 追加内容
with open('output.txt', 'a', encoding='utf-8') as f:
    f.write("追加的内容\n")

使用with语句

推荐使用with语句管理文件，它会自动关闭文件。

with open('example.txt', 'r') as f:
    content = f.read()
# 文件在这里自动关闭

二进制文件操作

# 读取二进制文件
with open('image.png', 'rb') as f:
    binary_data = f.read()

# 写入二进制文件
with open('copy.png', 'wb') as f:
    f.write(binary_data)

CSV文件操作

import csv

# 读取CSV
with open('data.csv', 'r', encoding='utf-8') as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)

# 写入CSV
data = [
    ['姓名', '年龄', '城市'],
    ['张三', '25', '北京'],
    ['李四', '30', '上海']
]
with open('output.csv', 'w', encoding='utf-8', newline='') as f:
    writer = csv.writer(f)
    writer.writerows(data)

JSON文件操作

import json

# 读取JSON
with open('data.json', 'r', encoding='utf-8') as f:
    data = json.load(f)
    print(data)

# 写入JSON
data = {
    'name': '张三',
    'age': 25,
    'city': '北京'
}
with open('output.json', 'w', encoding='utf-8') as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

文件路径操作

import os
from pathlib import Path

# 获取当前工作目录
cwd = os.getcwd()
print(cwd)

# 列出目录内容
files = os.listdir('.')
print(files)

# 检查文件是否存在
print(os.path.exists('example.txt'))

# 获取文件大小
size = os.path.getsize('example.txt')
print(f"文件大小：{size} 字节")

# 使用pathlib（推荐）
path = Path('example.txt')
print(path.exists())
print(path.is_file())
print(path.is_dir())
print(path.suffix)
print(path.stem)

最佳实践

  1. 始终使用with语句管理文件
  2. 指定编码格式（通常使用utf-8）
  3. 处理可能的异常（如文件不存在）
  4. 使用pathlib进行路径操作
  5. 关闭文件前确保数据已写入
