Pandas数据分析教程

作者：孙八
日期：2024-04-15
类别：数据分析

Pandas是Python中最强大的数据分析库之一，它提供了高效的数据结构和数据分析工具。

安装Pandas：
pip install pandas

导入Pandas：
import pandas as pd

核心数据结构：
1. Series：一维标签数组
2. DataFrame：二维标签数据结构

Series：
import pandas as pd

# 创建Series
s = pd.Series([1, 2, 3, 4, 5])
print(s)

# 指定索引
s = pd.Series([1, 2, 3, 4, 5], index=['a', 'b', 'c', 'd', 'e'])
print(s)

# 从字典创建
data = {'张三': 85, '李四': 92, '王五': 78}
s = pd.Series(data)
print(s)

DataFrame：
# 创建DataFrame
data = {
    '姓名': ['张三', '李四', '王五'],
    '年龄': [25, 30, 28],
    '城市': ['北京', '上海', '广州']
}
df = pd.DataFrame(data)
print(df)

# 从CSV文件创建
df = pd.read_csv('data.csv')

# 从Excel文件创建
df = pd.read_excel('data.xlsx')

# 从JSON文件创建
df = pd.read_json('data.json')

基本操作：
# 查看前几行
print(df.head())

# 查看后几行
print(df.tail())

# 查看数据形状
print(df.shape)

# 查看列名
print(df.columns)

# 查看数据类型
print(df.dtypes)

# 查看基本统计信息
print(df.describe())

数据选择：
# 选择单列
print(df['姓名'])

# 选择多列
print(df[['姓名', '年龄']])

# 选择行（按位置）
print(df.iloc[0])  # 第一行
print(df.iloc[0:2])  # 前两行

# 选择行（按标签）
print(df.loc[0])  # 标签为0的行

# 条件筛选
print(df[df['年龄'] > 25])

数据清洗：
# 处理缺失值
print(df.isnull())  # 检查缺失值
print(df.dropna())  # 删除包含缺失值的行
print(df.fillna(0))  # 用0填充缺失值

# 删除重复值
print(df.drop_duplicates())

# 数据类型转换
df['年龄'] = df['年龄'].astype(int)

数据聚合：
# 分组聚合
grouped = df.groupby('城市')
print(grouped.mean())

# 多个聚合函数
print(df.groupby('城市').agg({'年龄': ['mean', 'max', 'min']}))

数据合并：
# 合并DataFrame
df1 = pd.DataFrame({'A': [1, 2, 3], 'B': [4, 5, 6]})
df2 = pd.DataFrame({'A': [1, 2, 3], 'C': [7, 8, 9]})

# 内连接
merged = pd.merge(df1, df2, on='A')
print(merged)

# 连接
concatenated = pd.concat([df1, df2])
print(concatenated)

数据导出：
# 导出为CSV
df.to_csv('output.csv', index=False, encoding='utf-8-sig')

# 导出为Excel
df.to_excel('output.xlsx', index=False)

# 导出为JSON
df.to_json('output.json', orient='records', force_ascii=False)

常用函数：
- df.sort_values()：排序
- df.rename()：重命名列
- df.drop()：删除列或行
- df.apply()：应用函数
- df.pivot_table()：透视表
- df.crosstab()：交叉表
- df.value_counts()：值计数
