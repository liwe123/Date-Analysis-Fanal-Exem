NumPy科学计算基础

作者：周九
日期：2024-05-01
类别：数据分析

NumPy是Python科学计算的基础库，提供了高性能的多维数组对象和工具。

安装NumPy：
pip install numpy

导入NumPy：
import numpy as np

ndarray对象：
ndarray是NumPy的核心数据结构，是一个多维数组。

创建数组：
# 从列表创建
a = np.array([1, 2, 3, 4, 5])
print(a)

# 创建二维数组
b = np.array([[1, 2, 3], [4, 5, 6]])
print(b)

# 创建全零数组
zeros = np.zeros((3, 4))
print(zeros)

# 创建全一数组
ones = np.ones((2, 3))
print(ones)

# 创建等差数组
arange = np.arange(0, 10, 2)  # 0到10，步长为2
print(arange)

# 创建等间隔数组
linspace = np.linspace(0, 1, 5)  # 0到1，5个元素
print(linspace)

# 创建随机数组
random = np.random.rand(3, 3)  # 3x3的随机数组
print(random)

数组属性：
a = np.array([[1, 2, 3], [4, 5, 6]])

print(a.shape)      # 形状：(2, 3)
print(a.ndim)       # 维度：2
print(a.size)       # 元素总数：6
print(a.dtype)      # 数据类型：int32
print(a.itemsize)   # 每个元素的字节数：4

数组操作：
# 索引
a = np.array([1, 2, 3, 4, 5])
print(a[0])      # 1
print(a[-1])     # 5

# 切片
print(a[1:4])    # [2, 3, 4]
print(a[:3])     # [1, 2, 3]
print(a[2:])     # [3, 4, 5]

# 二维数组索引
b = np.array([[1, 2, 3], [4, 5, 6]])
print(b[0, 0])   # 1
print(b[1, 2])   # 6
print(b[0, :])   # 第一行：[1, 2, 3]
print(b[:, 1])   # 第二列：[2, 5]

数学运算：
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

# 逐元素运算
print(a + b)      # [5, 7, 9]
print(a - b)      # [-3, -3, -3]
print(a * b)      # [4, 10, 18]
print(a / b)      # [0.25, 0.4, 0.5]
print(a ** 2)     # [1, 4, 9]

# 聚合函数
print(np.sum(a))    # 6
print(np.mean(a))   # 2.0
print(np.std(a))    # 标准差
print(np.max(a))    # 3
print(np.min(a))    # 1
print(np.argmax(a)) # 最大值索引

数组变形：
a = np.arange(12)

# 重塑
b = a.reshape(3, 4)
print(b)

# 展平
c = b.flatten()
print(c)

# 转置
print(b.T)

广播机制：
NumPy的广播机制允许不同形状的数组进行运算。

a = np.array([[1], [2], [3]])  # 形状：(3, 1)
b = np.array([10, 20, 30])     # 形状：(3,)

c = a + b  # 自动广播
print(c)
# [[11, 21, 31],
#  [12, 22, 32],
#  [13, 23, 33]]

线性代数：
a = np.array([[1, 2], [3, 4]])
b = np.array([[5, 6], [7, 8]])

# 矩阵乘法
print(np.dot(a, b))
print(a @ b)  # 另一种写法

# 矩阵转置
print(a.T)

# 求逆矩阵
print(np.linalg.inv(a))

# 求特征值和特征向量
eigenvalues, eigenvectors = np.linalg.eig(a)
print(eigenvalues)
print(eigenvectors)

随机数生成：
# 设置随机种子
np.random.seed(42)

# 生成随机整数
print(np.random.randint(0, 10, 5))  # 5个0-10的随机整数

# 生成正态分布随机数
print(np.random.randn(3, 3))  # 3x3的标准正态分布

# 生成均匀分布随机数
print(np.random.uniform(0, 1, 5))  # 5个0-1的均匀分布

常用函数：
- np.sin(), np.cos(), np.tan()：三角函数
- np.exp()：指数函数
- np.log()：对数函数
- np.sqrt()：平方根
- np.abs()：绝对值
- np.round()：四舍五入
- np.sort()：排序
- np.unique()：去重
