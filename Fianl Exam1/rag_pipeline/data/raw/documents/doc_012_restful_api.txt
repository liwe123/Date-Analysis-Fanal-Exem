RESTful API设计指南

作者：黄十四
日期：2024-07-15
类别：Web开发

REST（Representational State Transfer）是一种软件架构风格，用于设计网络应用的API。

REST原则：
1. 无状态：每个请求包含所有必要信息
2. 客户端-服务器：分离关注点
3. 可缓存：响应可以被缓存
4. 统一接口：使用标准HTTP方法
5. 分层系统：客户端不需要知道是否直接连接服务器

HTTP方法：
- GET：获取资源
- POST：创建资源
- PUT：更新资源（完整更新）
- PATCH：部分更新资源
- DELETE：删除资源

URL设计：
好的URL设计应该：
- 使用名词而不是动词
- 使用复数形式
- 使用小写字母
- 使用连字符分隔单词
- 保持简洁明了

示例：
GET    /api/users          # 获取所有用户
GET    /api/users/123      # 获取ID为123的用户
POST   /api/users          # 创建新用户
PUT    /api/users/123      # 更新ID为123的用户
DELETE /api/users/123      # 删除ID为123的用户

嵌套资源：
GET    /api/users/123/orders      # 获取用户123的所有订单
GET    /api/users/123/orders/456  # 获取用户123的订单456

查询参数：
GET /api/users?page=1&limit=10          # 分页
GET /api/users?sort=name&order=asc      # 排序
GET /api/users?city=北京&age>25         # 过滤

状态码：
2xx 成功：
- 200 OK：请求成功
- 201 Created：资源创建成功
- 204 No Content：删除成功

3xx 重定向：
- 301 Moved Permanently：永久重定向
- 302 Found：临时重定向

4xx 客户端错误：
- 400 Bad Request：请求格式错误
- 401 Unauthorized：未认证
- 403 Forbidden：无权限
- 404 Not Found：资源不存在
- 405 Method Not Allowed：方法不允许
- 409 Conflict：冲突
- 422 Unprocessable Entity：数据验证失败
- 429 Too Many Requests：请求过多

5xx 服务器错误：
- 500 Internal Server Error：服务器内部错误
- 502 Bad Gateway：网关错误
- 503 Service Unavailable：服务不可用

响应格式：
{
    "status": "success",
    "data": {
        "id": 123,
        "username": "zhangsan",
        "email": "zhangsan@example.com"
    },
    "message": "操作成功"
}

错误响应：
{
    "status": "error",
    "error": {
        "code": 400,
        "message": "请求参数错误",
        "details": [
            {
                "field": "email",
                "message": "邮箱格式不正确"
            }
        ]
    }
}

分页响应：
{
    "status": "success",
    "data": [...],
    "pagination": {
        "page": 1,
        "limit": 10,
        "total": 100,
        "total_pages": 10
    }
}

FastAPI入门：
FastAPI是一个现代、快速的Web框架，用于构建API。

安装：
pip install fastapi uvicorn

创建API：
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import Optional

app = FastAPI()

class User(BaseModel):
    username: str
    email: str
    age: Optional[int] = None

users = []

@app.get("/api/users")
async def get_users():
    return {"status": "success", "data": users}

@app.get("/api/users/{user_id}")
async def get_user(user_id: int):
    if user_id >= len(users):
        raise HTTPException(status_code=404, detail="用户不存在")
    return {"status": "success", "data": users[user_id]}

@app.post("/api/users", status_code=201)
async def create_user(user: User):
    users.append(user.dict())
    return {"status": "success", "data": user.dict()}

@app.put("/api/users/{user_id}")
async def update_user(user_id: int, user: User):
    if user_id >= len(users):
        raise HTTPException(status_code=404, detail="用户不存在")
    users[user_id] = user.dict()
    return {"status": "success", "data": user.dict()}

@app.delete("/api/users/{user_id}", status_code=204)
async def delete_user(user_id: int):
    if user_id >= len(users):
        raise HTTPException(status_code=404, detail="用户不存在")
    users.pop(user_id)
    return None

运行API：
uvicorn main:app --reload

认证和授权：
from fastapi import Depends, HTTPException, status
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials

security = HTTPBearer()

async def verify_token(credentials: HTTPAuthorizationCredentials = Depends(security)):
    if credentials.credentials != "valid_token":
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="无效的认证令牌"
        )
    return credentials.credentials

@app.get("/api/protected")
async def protected_route(token: str = Depends(verify_token)):
    return {"message": "这是受保护的路由"}

最佳实践：
1. 使用版本控制：/api/v1/users
2. 实现分页：避免返回大量数据
3. 使用缓存：减少数据库查询
4. 限流：防止API被滥用
5. 记录日志：便于调试和监控
6. 编写文档：便于其他开发者使用
7. 测试：编写单元测试和集成测试
