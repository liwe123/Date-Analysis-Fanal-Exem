# Impeccable Design Notes

## Design Context

### Users
课程项目团队成员、答辩评委和需要快速查证课程资料的同学。使用场景通常是项目验收、答辩准备、课程通知查询和大数据知识点复盘，用户需要快速得到可追溯、可信、容易扫读的回答。

### Brand Personality
冷静、证据感、学术但轻盈。界面应像一张干净的研究台面：信息密度足够高，但不会压迫用户；强调来源、检索过程和可验证性，而不是营销式包装。

### Aesthetic Direction
产品型界面，而不是落地页。浅色优先，跟随系统暗色模式；使用带轻微青绿色偏色的中性底色、墨色正文、少量青绿色作为操作强调、少量琥珀色作为证据提示。避免紫蓝渐变、玻璃拟态、渐变文字、过度圆角和装饰性光斑。

### Design Principles
1. 证据优先：回答、来源和相似度应形成清楚的阅读顺序。
2. 低噪声：减少 emoji、浮夸阴影和重复说明，把注意力留给问题和答案。
3. 任务流清晰：侧边栏承载状态、数据写入和检索设置，主区域专注对话。
4. 可扫描：使用稳定字号、紧凑间距、标签化元数据和清晰的空状态问题入口。
5. 保持克制：视觉记忆点来自排版、色彩克制和细节，而不是大面积装饰。
