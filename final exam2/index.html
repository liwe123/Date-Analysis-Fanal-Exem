Big Data Course Project

课程知识库 RAG 助手

一个面向课程资料的大数据检索增强生成项目，覆盖文档摄取、文本清洗、 分块、ChromaDB 持久化索引、SQLite 兜底检索、意图解析与答案生成。 当前 Vercel 部署提供项目线上入口；完整 Streamlit 交互服务建议在本地或云主机运行。

查看 GitHub 项目 查看运行方式
本地 Web 启动 streamlit run app/streamlit_app.py
命令行问答 python src/main.py ask --question "课程项目提交要求是什么？"
部署说明 Streamlit 需要常驻进程和会话连接，Vercel 更适合静态页面与 Serverless Functions；因此这里部署为稳定的线上项目入口，避免上传本地模型和 9GB 向量库。
