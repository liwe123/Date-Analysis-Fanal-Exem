## 📌 第一部分：大白话项目全局图纸（我们的系统是怎么跑起来的？）

我们可以把这个 RAG（检索增强生成）系统看作是一家**“智能开卷考试辅助咨询公司”**。

1. **Streamlit 网页前端 (app/streamlit_app.py)**：是公司的**“接待大厅（前台）”**。用户在这里用大白话输入提问。
2. **Python 后端业务线 (src/)**：是公司的**“总机和参谋部”**。
   * 当用户问了一句：“2025年的紧急通知里讲了什么？”，前台把话传给总机。
   * **总机派任务**：
     * **意图解析师 (src/query_parser.py)**：先分析这句话，提取出核心词“通知”，并发现限制条件“年份是2025年”。
     * **翻译官 (scripts/embedding_server.py)**：用云端 RTX 4090 显卡（本地翻译官显卡太弱，去云端租用 4090）把问题翻译成一串 1024 维的数字向量（语义门牌号）。
     * **图书管理员 (src/embed_store.py)**：去我们的**向量数据库 (ChromaDB)** 里翻书，根据 2025 年这个标签，找出和问题意思最接近的前 3 段文章，把它们拿出来。
     * **答案合成师 (src/qa.py)**：把这 3 段文章拼在一起，加上严格约束（只能根据这些话回答，不许胡说八道！），交在远程大模型（OpenAI/DeepSeek）手里。
     * 大模型提笔写出最终回答。
     * 接待大厅（Streamlit）像打字机一样，把字一个个蹦出来给用户看，并大方地在下方写上：*“参考自 project_requirements.md 第 12 行，相似度 90%。”*

## ⌨️ 第三部分：终端命令（小黑窗）与运行环境速成

答辩现场演示或者在自己电脑上运行，都需要用到控制台（命令行小黑窗）。请熟记以下极简操作：

### 1. 怎么在项目目录里打开小黑窗？
* **方法**：在 Windows 资源管理器里打开 `final exam2` 这个文件夹，按住键盘上的 `Shift` 键不要松开，在文件夹的空白处点击鼠标**右键**，在弹出的菜单中选择 **「在此处打开 PowerShell 窗口」**。

### 2. 怎么一键把整个项目运行起来的依赖装好？
* **运行命令**：
  ```bash
  pip install -r requirements.txt
  ```
* **后台在干嘛**：这行命令会根据根目录下的 `requirements.txt`（依赖清单），自动从国内镜像站下载并安装我们系统需要的所有 Python 第三方库（如 Streamlit、ChromaDB、FPDF2 等）。就像是按照购物清单一键把所有厨房调料买齐。

### 3. `.env` 配置文件的大白话含义
双击用记事本打开根目录下的 `.env` 文件，你会看到：
```env
OPENAI_API_KEY=sk-xxxx...              # 大模型接口的授权钥匙卡
OPENAI_EMBEDDING_MODEL=remote          # 表明我们把向量特征计算“卸载”到云端 4090 上，不占用本机显存
OPENAI_EMBEDDING_BASE_URL=https://...  # 租用的 AutoDL 4090 云端显卡的高速访问网址链接
```

### 🧑‍💻 数据工程师：张杰 — 语料采集、清洗与云端 GPU 算力卸载操作

作为数据工程师，你负责保证原始数据干净、源源不断，并负责在云端部署好 RTX 4090 GPU 嵌入服务提供极致算力。

#### 动作一：启动互联网多源语料抓取与清洗（现场展示）
* **小黑窗运行命令**：
  ```python
  python src/collect_corpus.py
  ```
* **这个动作在干嘛**：启动爬虫引擎。程序会飞速向 Wikipedia 的大数据、大模型技术词条发送 HTTP 请求，使用 BeautifulSoup 抓取 HTML 网页正文，并利用 html2text 去除网页中侧边栏、广告等 90% 以上的无用 HTML 噪点，转换为极其干净的 Markdown 语法文本，自动分类保存到 `data/raw/` 目录下。这代表了我们**强大的数据工程 ETL（提取、清洗、转换）能力**。

#### 动作二：部署并一键拉起云端 4090 GPU 向量服务
* **部署步骤**：
  1. 双击运行 `scripts/setup_autodl.sh`（或者在 AutoDL 的 SSH 终端里运行 `bash setup_autodl.sh`）。
  2. 脚本会自动在云服务器上执行：
     ```bash
     pip install fastapi uvicorn sentence-transformers torch
     python -c "from sentence_transformers import SentenceTransformer; SentenceTransformer('BAAI/bge-large-zh-v1.5')"
     python scripts/embedding_server.py
     ```
* **这个动作在干嘛**：在租用的 AutoDL 远程服务器上下载并安装深度学习框架 PyTorch，并自动从 Hugging Face 镜像站下载大小为 1024 维的高端中文嵌入模型 `BAAI/bge-large-zh-v1.5`（在普通电脑上根本跑不动）。最后，启动一个由 `FastAPI` 框架驱动的高性能 HTTP 接口服务，占用端口 `6008`，静静等待本地发送数据过来。

#### 动作三：一键执行 100 万行数据的云端卸载批量向量建库
* **小黑窗运行命令**：
  ```bash
  python -m src.main build --metadata-strategy jsonl_only
  ```
* **这个动作在干嘛**：开启百万级建库流水线。
  * 本地程序自动读取 `data/` 下 1,000,176 行的原始 JSONL 大数据。
  * 自动将文本进行四级语义感知切片，切成 1,215,021 个 Chunk。
  * **云端卸载**：本地以 `batch_size=256` 批量打包，把文本并发发送给 AutoDL 4090 的 FastAPI 网址，利用 4090 极强的显卡 CUDA 算力进行高速特征向量转化（约 10000 条/秒）。
  * 本地拿到返回的向量数值后，以 upsert 幂等写入方式存入本地的 ChromaDB 中。仅耗时 2.5 小时、花费 4.70 元，就完成了原本本地需要几十小时的建库任务！

作为测试和保障工程师，你负责在项目发版前一键执行全部测试套件以证明代码零 Bug，并负责数据物理备份以应对灾天损坏。

  ```bash
  python -m pytest tests/ -v
  ```
* **这个动作在干嘛**：启动 Pytest 自动化测试实验室。
  * 程序会飞速扫描 `tests/` 下的所有 test 开头的测试函数。
  * **离线 Mock 推理**：执行过程中遇到连接大模型和远程向量库时，我写的 Mock 模拟装配器会自动拦截网络请求，并提供高保真度的数据返回（如模拟一段大模型回答和 ChromaDB 检索评分）。
  * 最终，**91 个单元测试和集成测试用例 100% 成功通过！**这彻底向评委证明，我们的系统具有极强的代码健壮性、架构解耦度以及持续集成（CI）规范度。

#### 动作二：对 5.8GB 的向量数据库进行物理打包快照备份
* **小黑窗运行命令**：
  ```bash
  tar -czvf vector_store_backup.tar.gz vector_store/
  ```
* **这个动作在干嘛**：物理备份。因为 ChromaDB 底层就是本地文件夹 `vector_store/` 内的几个 SQLite 和 Parquet 磁盘文件。这行命令将整个文件夹打包并高比例压缩为一个 `vector_store_backup.tar.gz` 快照文件，你可以通过网盘上行同步云端冗余备份。

#### 动作三：遭遇灾难时 1 秒解包恢复数据库
* **操作步骤**：
  1. 模拟数据库损坏：在资源管理器中直接右键删除 `vector_store` 这个文件夹（或者提问报错 DuplicateIDError 等数据库死锁异常）。
  2. 小黑窗运行命令：
     ```bash
     tar -xzvf vector_store_backup.tar.gz
     ```
* **这个动作在干嘛**：秒级灾难恢复。压缩包解包后，会在 1 秒内原地重构出完全一模一样的 `vector_store/` 文件目录。直接双击运行网页即可 100% 满状态原地复活，免去了漫长痛苦的 2.5 小时重跑建库流程，向评委展示了你极强的高可用（HA）保障与灾备能力。
