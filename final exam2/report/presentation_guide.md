## 三、演示前启动步骤

### 1. 启动本地服务

```powershell
# 嵌入服务，默认端口 6008
python scripts/embedding_server.py --model models/bge-large-zh-v1.5 --port 6008

# Web 前端，默认端口 8502
.venv\Scripts\python.exe -m streamlit run app/streamlit_app.py --server.port 8502
```

健康检查：

```powershell
Invoke-RestMethod http://localhost:6008/health
Invoke-WebRequest http://localhost:8502/_stcore/health -UseBasicParsing
```

### 2. 启动 `.com` 公网地址

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start_public_streamlit.ps1
```

脚本会检查 `8502` 健康状态，并启动 Cloudflare Quick Tunnel。终端出现
`https://xxxx.trycloudflare.com` 后，用手机流量打开并验证一次。

注意：

- Quick Tunnel 地址每次重启会变化，必须保留 `cloudflared` 进程。
- 公网地址仍依赖本机 Streamlit 和网络，不能关闭电脑或服务。
- 固定自定义域名需要创建 Named Tunnel 并配置 Cloudflare DNS，不属于 Quick Tunnel。
- localhost 始终作为现场备用入口。

### 4. 李伟：检索链路与技术权衡（3 分钟）

```text
用户问题
  -> query_parser.py：提取搜索词和可选过滤条件
  -> Chroma/HNSW 或 Chroma SQLite 正文检索
  -> 原始语料关键词兜底
  -> qa.py：基于参考资料生成答案并附来源
```

> 系统不把“使用向量库”当成唯一目标，而把可用性和可追溯性放在前面。当前 local 模式在线查询
> 会优先使用百万行 SQLite 正文索引，避免重复加载本地嵌入模型；当 SQLite 没有可靠结果时，
> 再使用原始语料兜底。Token 配额问题还会过滤只讲 session expired 的误召回，避免把不同故障
> 混为一谈。

## 五、高频问答

### Q1：为什么不用纯关键词搜索？

关键词搜索速度快，但同义表达容易漏召回。系统保留关键词兜底，同时通过查询解析和向量语义能力
处理“交作业”和“提交要求”等字面不同但语义接近的问题。

### Q2：为什么选择 BAAI/bge-large-zh-v1.5？

该模型面向中文语义检索，输出 1024 维向量，可本地或通过兼容服务运行。选择它主要考虑中文效果、
可离线部署和数据不必发送给第三方嵌入 API。实际环境以 `.env` 配置为准。

### Q3：为什么真实问答有时需要十几秒？

主要耗时来自远程 LLM 的查询解析和答案生成。检索与知识库状态统计不是主要瓶颈。
可通过缓存解析结果、减少上下文、降低 `top_k`、采用更快模型或本地部署 LLM 优化。

### Q4：如何降低幻觉？

系统提示词要求仅依据参考资料回答，检索结果附来源，距离阈值过滤低相关内容，缺少资料时明确说明。
这些措施降低风险，但不能承诺任何生成模型绝对零幻觉。

### Q5：Token 用完怎么办？

先区分四类错误：余额或配额耗尽应充值、换 Key 或切备用模型；HTTP 429 应退避并降低并发；
上下文超限应截断、摘要或分块；认证 Token 过期应刷新凭据。系统已加入对应 FAQ 和回归测试。

### Q6：为什么 Web 在线写入被关闭？

当前是 local embedding 模式。Web 在线写入会在前端进程加载大型本地模型，容易造成页面卡顿和显存竞争。
因此在线写入主动关闭，新增语料通过离线流程完成；切换 remote/openai embedding 后可再启用。

### Q7：公网地址为什么会变化？

当前使用 Cloudflare Quick Tunnel，它为临时演示生成随机 `trycloudflare.com` 地址。
需要固定域名时，应使用 Named Tunnel、Cloudflare DNS 和持久运行的 connector。

### Q8：百万级索引损坏怎么办？

保留原始语料和可重复执行的建库流程，索引文件另行备份。在线问答还有 SQLite 正文和原始语料回退，
但完整向量能力恢复仍需要还原备份或重新建库。
