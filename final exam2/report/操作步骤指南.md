# 手动操作步骤指南

## 任务一：编译 LaTeX 双栏 PDF

### 方法 A：使用 Overleaf（推荐，最简单）

1. 打开浏览器，访问 https://www.overleaf.com ，注册/登录
2. 点击 **New Project** → **Blank Project**
3. 项目名填 `RAG-Report`
4. 删除编辑器中的默认内容，将 `report/report_ieee.tex` 的全部内容粘贴进去
5. 点击左上角 **Menu**，将 **Compiler** 改为 **XeLaTeX**
6. 点击绿色 **Recompile** 按钮
7. 如果中文字体报错（SimSun 不可用），将 `\setCJKmainfont{SimSun}` 改为：
   - macOS：`\setCJKmainfont{Songti SC}`
   - Overleaf Linux：`\setCJKmainfont{Noto Serif CJK SC}`（需在 Menu → Compiler 设为 LuaLaTeX）
8. 编译成功后，点击右上角下载 PDF

### 方法 B：使用本地 VS Code + LaTeX Workshop

1. 安装 TeX Live（Windows：下载 https://www.tug.org/texlive/acquire-netinstall.html ，运行 `install-tl-windows.exe`，选完整安装约 5GB）
2. 安装 VS Code，扩展商店搜索安装 **LaTeX Workshop**
3. 用 VS Code 打开 `report/report_ieee.tex`
4. 按 `Ctrl+Alt+B` 编译（或点击左侧 TeX 图标 → Build LaTeX project）
5. 选择编译器为 **XeLaTeX**
6. 编译成功后 PDF 自动出现在同目录下 `report_ieee.pdf`

### 方法 C：使用命令行

```powershell
cd "D:\date analysis\final exam2\report"
xelatex report_ieee.tex
xelatex report_ieee.tex    # 运行两次确保引用正确
```

### 常见问题

| 问题 | 解决方案 |
|------|---------|
| `SimSun not found` | 改用系统已有的中文字体：`fc-list :lang=zh` 查看可用字体 |
| `xeCJK.sty not found` | 确保安装了完整 TeX Live（含 CJK 包） |
| 内容超出 6 页 | 删减附录表格或缩小 `\small` 字号；移除部分代码块 |
| 双栏表格跨栏 | 将 `table` 环境改为 `table*`，表格会占满整页宽度 |

## 任务二：导出 Mermaid 架构图并嵌入报告

### 方法 A：使用 mermaid.live 在线导出（推荐）

1. 打开浏览器，访问 https://mermaid.live
2. 左侧编辑器中默认有一些示例代码，全部删除
3. 打开 `report/architecture_diagram.md`，复制 ` ```mermaid ` 和 ` ``` ` 之间的全部内容
4. 粘贴到 mermaid.live 左侧编辑器
5. 右侧会实时渲染出架构图
6. 点击上方工具栏的 **Actions** → **Download PNG**（或 **Download SVG**）
7. 保存为 `report/architecture.png`

### 方法 B：使用 Mermaid CLI（命令行）

1. 安装 Node.js（https://nodejs.org ，LTS 版本）
2. 安装 mermaid-cli：
   ```powershell
   npm install -g @mermaid-js/mermaid-cli
   ```
3. 将 Mermaid 代码单独保存为 `report/architecture.mmd`（纯文本，不含 ` ```mermaid ` 标记）
4. 运行导出：
   ```powershell
   cd "D:\date analysis\final exam2\report"
   mmdc -i architecture.mmd -o architecture.png -w 1200 -b white
   ```
5. 生成 `architecture.png`

### 嵌入 LaTeX 报告

在 `report_ieee.tex` 的 `\section{系统架构}` 下方添加：

```latex
\begin{figure*}[t]
  \centering
  \includegraphics[width=\textwidth]{architecture.png}
  \caption{RAG 系统架构图：从原始文档到可查询向量索引的完整数据流}
  \label{fig:architecture}
\end{figure*}
```

注意：
- 用 `figure*` 而非 `figure`，这样图片跨双栏占满整页宽度
- 图片文件 `architecture.png` 需与 `.tex` 文件在同一目录
- 如果图片太大，调整 `width=0.9\textwidth` 缩小

